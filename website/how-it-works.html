System Overview

The Physical Hardware in Your Room

NexusHome is an independent physical unit installed on your wall. Here is what makes it tick:

ESP32 Central Brain

A dual-core 240MHz microcontroller coordinating all devices without blocking. It calculates motor progress, drives the OLED screen at 20 frames per second, and saves states instantly.

Isolated Heavy-Duty Relays

Physical electromagnetic switches that isolate sensitive electronics from high-power loads. They control the 7W LED light, 15W cooling fan, and motorized curtain directions safely.

DHT22 Digital Temperature Sensor

Samples ambient room temperature every 2.5 seconds with high digital accuracy. It drives the automatic cooling logic so your room stays comfortable automatically.

VC-02 Edge Voice AI

An offline speech processor trained on acoustic wave patterns. It listens only for the wake word "Nexus" and recognizes spoken commands in less than 200 milliseconds without internet.

System Behavior

Two Operating Modes: Automatic vs. User Mode

NexusHome is designed to give you effortless climate regulation when you want it, and complete direct authority whenever you need it.

Automatic Mode

OLED Status: AUTO • Voice: "Nexus, automatic mode"

In Automatic Mode, the ESP32 actively monitors room temperature via the DHT22 sensor:

  • Temperature ≥ 30.0°C: The cooling fan turns ON automatically, accompanied by a distinct 1.5-second buzzer chime.
  • Temperature ≤ 29.0°C: Once cooled down, the cooling fan turns OFF automatically.
  • Hysteresis Deadband (1°C): The gap between 30°C and 29°C prevents rapid clicking on/off if the temperature hovers around the boundary.
  • Smart Manual Override: If you manually turn the fan off during auto mode, it stays off until the temperature drops below 29°C, respecting your choice.
Spoken: "automatic mode" OLED Display: AUTO ≥30°C Fan ON ≤29°C Fan OFF

User Mode (Manual Override)

OLED Status: MANUAL • Voice: "Nexus, user mode"

In User Mode, automatic temperature triggers are paused, giving you full direct manual authority:

  • Spoken Voice Trigger: Speak "Nexus, user mode" to enter this mode effortlessly.
  • OLED Status Display: The status bar on the OLED display registers this as manual control and prominently shows MANUAL.
  • Safety Auto-OFF: When switching into User Mode, the fan turns OFF initially for safety and clears prior automatic overrides.
  • Direct User Command: You have 100% control over lighting, fan speeds, and curtains via your phone, widget, quick tiles, or voice commands.
Spoken: "user mode" OLED Display: MANUAL Automations Paused Full User Control

Precision Actuation

25-Second Motorized Curtains with Blackout Memory

How the motorized curtain traverse works and protects against sudden power disruptions:

Phase 1 • Smooth Traverse

Calibrated 25s Movement

A heavy-duty 12V 30RPM worm-gear motor drives the curtain track. It takes exactly 25 seconds for a complete open or close cycle. Both the physical OLED screen and the Android app display a smooth, live progress bar as it travels.

Phase 2 • Power Outage Protection

Non-Volatile Checkpoints

Every 500 milliseconds during movement, the ESP32 saves the exact elapsed run time into its non-volatile flash memory (NVS). If mains power is abruptly cut mid-motion, the physical position is not lost.

Phase 3 • Reboot Recovery

Automatic Resume

When power returns or the solar backup kicks in, the ESP32 reads the checkpoint and resumes only the remaining seconds needed to finish opening or closing. It never runs past the calibrated end.

Spoken Cheat Sheet

Voice Commands Reference (Wake Word: "Nexus")

Always say the wake word "Nexus" first. After the brief acknowledgement chime, speak any of the following phrases naturally:

Spoken Command Target Actuator System Action & Display
"lights on" GPIO2 Relay (7W LED Light) Turns room light ON; OLED displays LIGHT: ON; state saved to memory
"lights off" GPIO2 Relay (7W LED Light) Turns room light OFF; OLED displays LIGHT: OFF; state saved to memory
"fan on" GPIO15 Relay (15W Cooling Fan) Turns fan ON; OLED displays FAN: ON; overrides automatic fan state
"fan off" GPIO15 Relay (15W Cooling Fan) Turns fan OFF; OLED displays FAN: OFF; overrides automatic fan state
"open curtain" GPIO18/19 Relays (JGY-370 Motor) Traverses curtains forward for 25s with real-time filling progress bar on OLED
"close curtain" GPIO18/19 Relays (JGY-370 Motor) Traverses curtains reverse for 25s with real-time draining progress bar on OLED
"automatic mode" Climate Control Engine Enables DHT22 automatic fan cooling (≥30°C ON / ≤29°C OFF); OLED status bar displays AUTO
"user mode" Manual Override Engine Switches to direct manual control; OLED status bar displays MANUAL; disables auto temperature triggers; turns fan OFF initially for safety
"goodbye" / "bye" VC-02 Module Standby Plays friendly exit chime and returns speech processor to low-power listening mode
